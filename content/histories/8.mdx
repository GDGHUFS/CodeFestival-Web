### 진행 방법
- **알고리즘 트랙**과 **AI 트랙**으로 나누어 **개인전**으로 진행

| **구분**       | **알고리즘 트랙**          | **AI 트랙**                       |
| -------------- | -------------------------- | --------------------------------- |
| 평가 목표      | 알고리즘 설계 및 구현 능력 | 생성형 AI를 활용한 문제 해결 능력 |
| 문제 유형      | 프로그래밍 문제            | 프롬프트 작성형 문제              |

<!-- 3.2 알고리즘 트랙 -->
### 알고리즘 트랙

#### 채점 기준
- 제출한 소스 코드를 컴파일 및 실행한 결과로 자동 채점
- 테스트케이스별로 부분 점수 부여
  - 모든 테스트케이스를 통과하지 못해도, 통과한 테스트케이스만큼 점수를 받을 수 있음
  - 컴파일 오류, 시간 초과, 메모리 초과 및 오답인 테스트케이스는 점수를 받을 수 없음
- 문제별로 가장 높은 점수를 받은 제출을 인정하며, 모든 문제의 점수를 합산하여 순위 결정
  - 총점이 같으면 해당 점수에 더 빨리 도달한 참가자가 우위

#### 개발 언어 및 컴파일 환경
| **언어**       | **컴파일러/버전**           |
| -------------- | --------------------------- |
| **C**          | GCC 13.3.0 (gnu17)          |
| **C++**        | G++ 13.3.0 (gnu++17)        |
| **Java**       | OpenJDK 21                  |
| **Python 3**   | PyPy 7.3.15 (Python 3.9)    |
| **JavaScript** | Node.js 24.22.2             |
| **Kotlin**     | 2.2.20 (OpenJDK 21)         |
| **C#**         | .NET 10.0                   |
| **Rust**       | rustc 1.75.0 (edition 2021) |

- 언어마다 시간 제한 배수와 추가 메모리가 다르게 적용됨


<!-- 3.3 AI 트랙 -->
### AI 트랙

#### 진행 방법
- 대회에서 제공하는 생성형 AI를 활용해 **프롬프트 작성형** 문제를 해결
- 응시 화면의 편집기에서 프롬프트를 작성하고, 공개 테스트케이스로 결과를 확인하며 프롬프트를 개선
- 최종 제출한 프롬프트를 비공개 테스트케이스에 적용하여 채점
- 특정 전공 지식이 없어도 도전할 수 있도록 언어, 데이터, 추론 등 다양한 분야에서 출제

#### 제공 AI 모델
- 공정한 대회 환경을 위해 구체적인 모델 정보는 제공하지 않음

#### 채점 방식
- 제출한 프롬프트를 대회에서 제공하는 AI 모델에 적용하여 채점
- 비공개 테스트케이스에 대한 정답률을 기준으로 점수 산정
- 필요에 따라 토큰 사용량을 점수에 반영할 수 있음


<!-- 3.4 응시 환경 -->
### 응시 환경
- 각 캠퍼스 대회장의 PC에서 HUFS CODE MASTER에 접속하여 진행
- 개인 노트북 및 전자기기는 사용할 수 없음
- GitHub Copilot, ChatGPT, Claude 등 외부 생성형 AI 도구와 인터넷 검색은 모든 트랙에서 사용할 수 없음
> 대회 중에는 응시 화면에 제공된 리소스만 열람할 수 있음

#### 3. 대회 문제 및 채점
- 알고리즘 트랙은 총 8문제가 출제되며, 통과한 테스트케이스에 따라 부분 점수를 받을 수 있습니다. 모든 문제의 점수를 합산하여 순위를 정합니다.

- 자세한 채점 기준은 [알고리즘 트랙](#3-알고리즘-트랙)과 [AI 트랙](#3-ai-트랙) 안내를 참고하시기 바랍니다.

#### 4. 응시 환경 및 제한 사항
- 각 캠퍼스에서 지정된 대회장의 PC를 사용해야 하며, 개인 전자기기는 허용되지 않습니다.
- 알고리즘 트랙 참가자는 [개발 언어 및 컴파일 환경](#4-개발-언어-및-컴파일-환경)에 명시된 프로그래밍 언어를 사용할 수 있습니다.
- 대회 중에는 인터넷 검색 및 외부 자료 열람이 금지되며, 응시 화면에 제공된 리소스만 열람할 수 있습니다.

#### 5. 부정행위 금지
- **부정행위** 시 대회에서 즉시 실격 처리되며, 향후 대회 참여가 제한될 수 있습니다.
- **공통 부정행위의 예시:**
  - 개인 전자기기 사용
  - 타 참가자와의 대화 또는 문제 풀이 공유
  - 인터넷 검색을 통한 외부 자료 활용
  - 허가되지 않은 소프트웨어 사용
  - 대회에서 제공하지 않는 생성형 AI 사용
- **AI 트랙 부정행위의 예시:** AI 트랙은 기본적으로 프롬프트에 참가자가 직접 문제를 풀이한 내용이 담겨야 합니다.
  - **풀이를 AI에게 떠넘기기:** "~에 대한 규칙을 찾아줘"처럼 참가자가 직접 찾아야 하는 규칙이나 풀이를 AI가 대신 찾게 하는 프롬프트
  - **프롬프트 인젝션:** 주어진 지시를 무시하게 하거나, 채점 기준 등 공개되지 않은 정보를 알아내거나, 채점 결과를 조작하려는 프롬프트

#### 6. 대회 종료 및 시상식
